# Northstar Support Escalation Guide

Document ID: KB-012
Last updated: 2026-09-30
Owner: Support Operations

## Purpose
Use this guide when a support agent cannot resolve an issue
using the documented troubleshooting steps.

## Routing requests
- Billing Operations: refund requests, duplicate charges,
  disputed charges, and repeated payment failures.
- Technical Support: unresolved sign-in problems, import
  failures, integration issues, and slow performance.
- Security Operations: suspected unauthorized access and
  account recovery without an authenticator or recovery codes.
- Account manager: Enterprise contract terms and pricing.

References to the "Security team" in other guides mean
Security Operations.

## Urgency
Escalate suspected unauthorized access immediately.

For technical issues:
- High: multiple users cannot complete essential work.
- Normal: one user is affected or a workaround is available.

Include the business impact so the receiving team can
assess priority.

## Required details
Include:
- Workspace name
- Brief description of the issue
- When it started, including timezone
- Number of affected users
- Exact error message, with sensitive values removed
- Troubleshooting steps already attempted
- Relevant invoice or import ID, if applicable

Never include passwords, authentication codes, recovery
codes, API keys, or full payment card details.

## Customer communication
Explain which team will review the issue and summarize
the information provided.

Do not promise an approval, outcome, or resolution time.
This guide does not define response-time guarantees
or support operating hours.

## Tracking
Record the escalation reference in the original support
ticket so future updates stay connected to the issue.
