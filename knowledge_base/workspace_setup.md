# Setting Up a Northstar Workspace

Document ID: KB-007
Last updated: 2026-09-30
Owner: Customer Onboarding

## Before you start
You need a verified Northstar account to create a workspace.
The person who creates the workspace becomes its owner.

## Creating a workspace
1. Sign in to Northstar.
2. Select "Create workspace."
3. Enter a workspace name.
4. Choose a standard subscription plan.
5. Complete the billing steps shown on screen.
6. Select "Finish setup."

See KB-005: Northstar Subscription Plans for user and
storage limits. This guide does not specify trial availability.

## Workspace roles
- Owner: manages billing, workspace settings, and members.
- Admin: manages workspace settings and members, but not billing.
- Member: works with content but cannot manage billing or members.

Only owners can assign or remove the owner role.
A workspace must always have at least one owner.

## Initial configuration
Open Settings → General to set the workspace name and timezone.
Only owners and admins can change these settings.

The workspace timezone controls how timestamps appear in
shared reports. It does not change each user's device timezone.

## Next steps
After setup:
1. Invite teammates.
2. Import existing data.
3. Confirm teammates can access the workspace.

## Setup problems
If workspace creation fails, record the error message and
contact Northstar Support.

Never include passwords, authentication codes, or full
payment card details in a support request.
