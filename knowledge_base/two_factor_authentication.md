# Northstar Two-Factor Authentication

Document ID: KB-004
Last updated: 2026-09-30
Owner: Security Operations

## Who this applies to
Customers who sign in using an email address and password.
Customers using company single sign-on (SSO) must contact
their IT administrator about authentication requirements.

## Setting up two-factor authentication
1. Sign in to Northstar.
2. Open Settings → Security.
3. Select "Enable two-factor authentication."
4. Scan the QR code using an authenticator app.
5. Enter the six-digit code shown in the app.
6. Save your recovery codes in a secure location.

Northstar does not support authentication codes by SMS.

## Recovery codes
Each recovery code can be used only once.
Generating a new set invalidates all previous recovery codes.

Never share authentication or recovery codes with support agents.

## Lost access to an authenticator
If you saved your recovery codes, use an unused recovery code
in place of the authenticator code during sign-in.

After signing in, open Settings → Security to reconnect
your authenticator and generate new recovery codes.

## No authenticator or recovery codes
Contact Northstar Support to request account recovery.
Support must escalate the request to Security Operations
for identity verification.

Support agents cannot disable two-factor authentication.
This document does not specify a recovery completion time.

## Password resets
Resetting your password does not disable two-factor
authentication or replace the need for a second factor.
