# Troubleshooting Slow Performance

Document ID: KB-011
Last updated: 2026-09-30
Owner: Technical Support

## Scope
Use this guide when Northstar pages or reports load slowly.
For delayed integration syncs, see KB-010:
Troubleshooting Northstar Integrations.

## Initial checks
1. Check whether other websites are also slow.
2. Refresh the Northstar page.
3. Try a private or incognito browser window.
4. If performance improves in the private window, temporarily
   disable browser extensions and test again.
5. Ask whether other teammates experience the same issue.

Save any unsaved work before refreshing or closing a page.

## Slow reports
Narrow the report's date range and remove unnecessary filters,
then run it again.

This guide does not specify a guaranteed report loading time
or a maximum supported report size.

## When to escalate
Contact Northstar Support if the problem continues after
the initial checks.

If multiple teammates cannot complete their work because
of the slowdown, report the issue immediately and describe
its impact.

## Information to collect
Include:
- Workspace name
- Affected page or report
- When the issue started, including timezone
- Approximate loading time
- Browser name and version
- Whether one user or multiple users are affected
- Troubleshooting steps already attempted

Screenshots may help, but remove confidential information
before sharing them.

## Support boundaries
Support agents must not promise a resolution time before
Technical Support investigates the issue.
